# guia_redes

Guía paso a paso del proyecto final de **Redes II** en PNETLab: RIPv2, EIGRP y OSPF multimarca con redistribución, NAT, EtherChannel, ACL por VLAN, monitoreo con Zabbix y Grafana, y bot de Telegram con n8n.

**Ver la guía:** https://stivenrodriguezm.github.io/guia_redes/

Incluye:
- Topología, cableado y tabla de direccionamiento.
- Configuración completa de cada router, switch, servidor y PC, lista para copiar.
- Atajo para crear el lab en PNETLab y cargar todas las configuraciones con un script.
- Scripts de instalación de Zabbix 7.0, Grafana y n8n, y el flujo del bot.
- Pruebas con resultado esperado, checklist de las 23 evidencias y preguntas de sustentación.
